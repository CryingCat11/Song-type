# Допой строчку

Игра для друзей: играет клип с YouTube, строчки песни появляются под звук, нужно успеть набрать каждую. Один файл `index.html`, без бэкенда. Тексты с таймингами подгружаются в браузере с lrclib.net.

Песни: «ДИНАСТИЯ» (VILLIAN, madk1d), «67» (GAZAN), «Базовый минимум» (Sabi, MIA BOYKA), «Быть богатым» (Voskresenskii, Платина). Свои песни добавляются кнопкой «Добавить песню».

## Установка и обновление на сервере (Ubuntu)

```
curl -fsSL https://raw.githubusercontent.com/CryingCat11/Song-type/main/install.sh | bash
```

Тестовый режим без сети: `index.html?mock`.

## Точные тайминги под клип

`subs.sh` скачивает на сервер субтитры YouTube каждого клипа (в `/var/www/song-type/subs/`). Игра сверяет по ним текст песни слово в слово, поэтому строчки идут ровно под звук даже у клипов с длинным вступлением. Без субтитров текст идёт по таймингам альбомной версии.

    curl -fsSL https://raw.githubusercontent.com/CryingCat11/Song-type/main/subs.sh | bash -s <коммит>
