# Допой строчку

Игра для друзей: играет клип с YouTube, строчки песни появляются под звук, нужно успеть набрать каждую. Один файл `index.html`, без бэкенда. Тексты с таймингами подгружаются в браузере с lrclib.net.

Песни: «ДИНАСТИЯ» (VILLIAN, madk1d), «67» (GAZAN), «Быть богатым» (Voskresenskii, Платина). Свои песни добавляются кнопкой «Добавить песню».

## Установка и обновление на сервере (Ubuntu)

```
curl -fsSL https://raw.githubusercontent.com/CryingCat11/Song-type/main/install.sh | bash
```

Тестовый режим без сети: `index.html?mock`.
